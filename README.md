# pred-arbitrariness
MSc Project on "Arbitrariness of Predictions in High-Stakes Decision Making"

-	Investigated prediction instability in ensemble classifiers applied to high-stakes domains like criminal justice and credit risk, examining how arbitrary modelling choices produce divergent outcomes for the same individuals.
-	Designed systematic experiments varying model configurations to quantify the Rashomon effect, evaluated model reliability and fairness using self-consistency metrics, compared consistency-accuracy trade-offs across ensemble strategies and developed a Super Learner variant optimised for prediction consistency.
-	Findings contribute to improving the reliability and auditability of production-grade ML systems in high-stakes settings.
